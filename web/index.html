Three steps, no import wizard

  1. 01

    Point it at a folder

    Add Cullyard to your agent with one command and give it a workspace, say D:\Shoots\Bali. The desk opens on your machine at 127.0.0.1:4870.

  2. 02

    Drop files and say what you want

    Drag files from Explorer onto the desk. Then type in your agent: "keep the sharp harbor shots, park the blue hour set in Maybe, put contracts in Client docs."

  3. 03

    Watch it work, then overrule it

    Cards slide into lanes as the agent calls each tool. Disagree? Drag a card or press 1 to 9. Both of you edit the same folders, so nothing drifts.

A real run, recorded as it happened

This is the desk while a script drives the actual MCP server the way an agent does: scan, make a lane, sort ten of eleven files, resize a pick, trim a clip, seal the log on devnet, verify the seal. No mockups, no speed-up tricks beyond the frame rate.

  • 10 files sorted across 4 lanes
  • 1 WebP copy at 1200 px wide
  • 1 three-second clip cut without re-encoding
  • 1 devnet memo that matches the log hash

What your agent can call

Every tool returns plain JSON and fails with a readable message. Paths outside the workspace are refused, moves never overwrite, and edits always write a new file.

toolwhat it does
scan_workspaceLists every file with kind, size, pixel size, duration, tags or page count.
describe_fileMetadata for one file.
list_lanesCurrent lanes and which file sits where.
create_laneAdds a lane such as "Hero shots" or "Final cut".
move_to_laneMoves a file into a lane folder. Refuses to overwrite.
resize_imageWrites a resized WebP, JPG, PNG or AVIF copy.
trim_mediaCuts a time range from video or audio with no re-encode.
log_digestSHA-256 of the sorting log, computed locally.
seal_runWrites that hash into a Solana devnet memo.
verify_sealRecomputes the hash and checks it against the chain.
list_kindsThe file kinds Cullyard recognises.

Proof that a sort happened, and when

Photographers hand over selects, editors hand over cuts, assistants clean out a client's folder. Cullyard keeps an append-only log of every move. Sealing writes its SHA-256 into a memo on Solana devnet, so anyone with the log can check it was not edited after the fact. Your files and file names never go on-chain, only the hash.

Install

You need Node.js 20 or newer. FFmpeg ships with the package, so video and audio work out of the box on Windows. Replace the folder with your own.

claude mcp add cullyard -- npx -y github:bryankwandou/cullyard "D:\Shoots\Bali"
// mcp_config.json
{
  "mcpServers": {
    "cullyard": {
      "command": "npx",
      "args": ["-y", "github:bryankwandou/cullyard", "D:\\Shoots\\Bali"]
    }
  }
}
git clone https://github.com/bryankwandou/cullyard
cd cullyard && npm install && npm test
node bin/cullyard.js "D:\Shoots\Bali"     # MCP over stdio + desk on :4870

To seal runs, set CULLYARD_KEYPAIR to a devnet keypair file. Without it, sorting and editing work the same and seal_run politely says no.

What it does not do, yet

  • It does not judge photos by itself. Your agent decides; Cullyard gives it the facts and the hands.
  • No timeline editor. Trims and resizes are single steps, not a Premiere replacement.
  • Seals use devnet. A mainnet option waits until someone asks for it with a real workflow.
